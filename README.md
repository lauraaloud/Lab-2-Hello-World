# Hello World

This is my first website created for MI 349: Web Design and Development at Michigan State University.

### About the Project
This project is a simple HTML website created to practice the basics of web development. The page includes a Hello World message, an image, different HTML sections, a list, and an interactive details element.

### What I Practiced
- Creating an HTML5 webpage
- Using semantic HTML elements
- Adding and formatting an image
- Using lists and interactive HTML elements
- Using Git and GitHub to track changes
- Deploying a website with Netlify
